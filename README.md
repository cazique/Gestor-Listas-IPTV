# Gestor IPTV

App Android (móvil y Google TV, un solo APK) para **gestionar y limpiar** la lista IPTV de un proveedor Xtream Codes y exportarla en M3U para **TiviMate Premium**. No reproduce vídeo. Especificación completa en [`SPEC.md`](SPEC.md); decisiones en [`DECISIONES.md`](DECISIONES.md).
